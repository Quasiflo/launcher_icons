# Security Policy

## Supported Versions

Only the latest release is supported with security fixes.

If you are running an older version, please upgrade to the latest release before reporting.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please use GitHub private vulnerability reporting for this repository (Security tab -> Report a vulnerability).

When reporting, please include:

- The affected version, tag, or commit
- A description of the issue and why you believe it is security-sensitive
- Steps to reproduce or a proof of concept
- The potential impact
- Any suggested mitigations or fixes, if known

## What to Expect

These are small, low-risk projects maintained on a best-effort basis. We'll try to respond & fix the issue quickly!

If a report is validated, we will work on a fix and release it as soon as practical. Once remediation details are ready to share publicly, we may publish a GitHub Security Advisory.

We will credit reporters in the advisory unless you prefer to remain anonymous. Please inform us if this is the case.
